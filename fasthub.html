部署私有加速节点

用一个 Cloudflare Workers 免费部署你自己的代理节点，只有你一个人用，更稳定也更私密。

⚠️ 国内用户必读
Cloudflare Workers 的默认域名 xxx.workers.dev 在国内已被 DNS 污染，无法直接访问。必须绑定你自己的域名才能在国内正常使用。
📌 第一步：获取免费域名

如果你已经有域名，可以直接跳到第二步。如果没有，以下平台可以免费注册二级域名，并且都支持托管到 Cloudflare：

  • katabump.com — 后缀 kdns.fr，注册即永久，无需绑卡，在 PSL 列表中，支持 Cloudflare 托管
  • dnshe.com — 后缀 de5.net、cc.cd、us.ci、bot.cd 等，免费注册，支持 Cloudflare 托管
  • digitalplat.org — 后缀 dpdns.org、qzz.io 等，支持 Cloudflare 托管
  • nic.eu.org — 老牌免费域名，审核较慢但稳定
  • gv.uy — 后缀 gv.uy，运维活跃，支持 Cloudflare 托管

建议注册前先到 publicsuffix.org 查一下该后缀是否在 PSL 列表中，在列表里的才能正常托管到 Cloudflare。

📌 第二步：把域名托管到 Cloudflare
  1. 登录 Cloudflare，点击「添加站点」，输入你的域名
  2. 选择免费套餐，按提示到域名注册商处修改 NS 记录
  3. 等待 Cloudflare 完成域名验证（通常几分钟到几小时）
📌 第三步：部署 Worker 并绑定域名
  1. 进入 Cloudflare 的「Workers & Pages」，创建一个 Worker
  2. 把仓库里的 worker.js 代码粘贴到编辑器，保存并部署
  3. 进入该 Worker 的「设置」→「触发器」→「自定义域」
  4. 输入你托管在 Cloudflare 的域名，等待证书签发
  5. 完成后，用 https://你的域名/https://github.com/... 即可访问
